अभ्यासआरोह — शुरुआती वेबसाइट/PWA प्रोटोटाइप

चलाने का तरीका:
1. इस फोल्डर को किसी वेब होस्टिंग पर HTTPS के साथ अपलोड करें, या स्थानीय सर्वर चलाएँ।
2. index.html खोलें। PWA इंस्टॉल और ऑफलाइन cache के लिए HTTPS आवश्यक है।
3. मोबाइल ब्राउज़र के Add to Home Screen से इसे होम स्क्रीन पर जोड़ सकते हैं।

महत्वपूर्ण:
यह अभी केवल फ्रंट-एंड प्रोटोटाइप है। इसमें नमूना प्रश्न हैं, लाइव AI, आधिकारिक स्रोतों से ऑटो-इम्पोर्ट, लॉगिन, डेटाबेस, एडमिन पैनल, भुगतान, या वास्तविक cloud sync नहीं है।
ऐप स्टोर रिलीज़, वास्तविक Android/iOS पैकेज, सर्वर, डेटा सुरक्षा और कंटेंट लाइसेंसिंग अलग से बनानी होगी।
